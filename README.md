One original fortune-cookie line for a software developer, written by a
program for the make.fun bounty
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

Running `main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`:

> You will deploy on Friday, and the weekend will keep its own changelog.

The line is 71 characters — inside the 120-character cap. It names a true
developer's-day pain, the Friday deploy, and turns it in the last few words:
the weekend keeps its own changelog.
